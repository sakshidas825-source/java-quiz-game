
# Java Quiz Game

A console-based Quiz Application developed using Core Java, Object-Oriented Programming, ArrayLists, and user input handling.

## Features
- Multiple-choice questions
- Real-time score tracking
- Performance evaluation
- Object-Oriented Design
- Dynamic question management using ArrayList

## Technologies Used
- Java
- OOP
- ArrayList
- Scanner

## How to Run

1. Compile the program:
   javac quizGame.java

2. Run the program:
   java quizGame
