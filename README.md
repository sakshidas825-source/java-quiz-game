 🎯 Java Quiz Game

Test your knowledge, challenge yourself, and level up your Java skills! 🚀

Java Quiz Game is a console-based quiz application built using Core Java. It presents users with multiple-choice questions, tracks scores in real time, and provides performance feedback at the end of the quiz.

✨ Features

* 📝 Multiple-choice quiz questions
* 🎯 Instant answer validation
* 📊 Real-time score tracking
* 🏆 Performance evaluation and grading
* 🔄 Easily expandable question bank
* 💡 Object-Oriented Programming implementation

🛠️ Tech Stack

* Java
* Object-Oriented Programming (OOP)
* ArrayList Collections Framework
* Scanner Class
